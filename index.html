ディポトGM、先発投手トレードの可能性を否定せず
  • マリナーズのジェリーディポトGMは、以前は先発投手のトレードに否定的だったが、今オフは「聞く耳を持つ」姿勢に転換。打線の強化やブルペンの補強につながるなら、先発投手の放出を検討する意向を示した。

マリナーズはいかに守備の苦境を乗り越えるか
  • マリナーズは2026年に76勝86敗と期待外れに終わり、リーグで最も遅いチーム（スプリントスピード 26.9 ft/sec、ホームから一塁まで 4.50 sec）だった。Statcastの守備指標では平均より59失点悪く、リーグ最悪の守備力を記録し、Defensive Runs Savedでも「かなり悪い」と評価された。
  • ジェリーディポトGMは、最近のGM会議で「守備の改善が最優先事項であり、昨年の守備はひどかった」と明言。「良い投手陣が好調を維持し、試合に勝つことを非常に困難にしている」と述べ、守備の悪さがチーム全体のパフォーマンスに与える悪影響を強調した。
  • StatcastのFielding Run Valueによると、守備の良い上位半分のチームの2/3がプレーオフに進出しており、守備力と勝利の相関関係は高い。ディポトGMは「最も手っ取り早いのは、守備を強化できる選手を見つけること」と語っており、守備の弱い選手（J.P. Crawford、Randy Arozarena、Luke Raleyなど）の多くが2027年にチームを去る可能性があり、これが守備改善の機会となる。
